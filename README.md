# Prediction of used cars' prices
## Project Overview
This project aims to perform a comprehenisve data pipeline in order to build the best machine learning model that predicts prices for the used cars across central Europe.  
## Project Objectives
1. Idetify the data source - [autoscout24](https://www.autoscout24.com/)
2. Create a data pipeline
3. Orchestrate and schedule the pipeline
4. Set up CI/CD
5. Arrange containerization
6. Set up observability for monitoring
7. Arrange visualisation of results
## Tech Stack
- Python. 
- Selenium and Requests for parsing. 
- Airflow. 
- GitHub. 
- Docker. 
- Grafana. 
- FastAPI.
